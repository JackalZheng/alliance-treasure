# 聯盟寶藏 輔助查詢
純前端網頁（`index.html` + `codes.json`），部署於 GitHub Pages。`codes.json` 為 516 張全開解答圖離線辨識出的 10×12 代號格（不含任何圖片）。
## 使用
1. 在「目前盤面」點格子，設定已翻開的圖案（只看到一部分也算該圖案；翻開沒東西選「空白」）。
2. 右側即時列出符合的候選解答（色塊縮圖＋檔名），點選可看完整代號格，綠框=符合、紅框=不符。
3. 選用：選擇本機「寶藏地圖（全開）」資料夾，預覽時可疊加顯示原圖（只在瀏覽器讀取，不上傳）。
4. ⚠️ 標記的圖為未全開或辨識可疑，可勾選隱藏。
代號：A 箭矢、K 鑰匙、C 寶箱、W 皇冠、G 齒輪骰子、H 錨、B 弓、E 空白、? 未翻開
